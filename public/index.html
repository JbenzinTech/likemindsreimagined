Cloud Sync
Set a sync code below, then enter the same code on every device this fund is managed from. All fund data and user accounts (including passwords) are shared across every device using that code — treat it like a master password for the fund. Once set, changes save to the cloud automatically while you're online; if you go offline, changes are held locally and sync automatically once you reconnect. A brand-new device can also connect to an existing fund from the login screen, before creating any local account — see "Already have a fund on another device?" there.
Manual sync
Sync now pushes if this device has unsynced local edits, otherwise pulls the latest cloud copy. Push/Pull force a direction — use them if something looks out of sync. A pull also refreshes user accounts and roles from the cloud, and will log you out if your account was changed or removed elsewhere.

Record a transaction
Buy adds units at cost (price × units + charges, posted to Investments at Fair Value). Sell reduces units using average cost to compute realised gain/loss, posted to account 4200. Settlement account is the asset account debited/credited on the cash side (defaults to Cash and Cash Equivalents). Asset ID is optional and links this transaction to a Portfolio → Register entry — tag transactions this way so their cost basis is picked up by that Register item's Cost figure under Portfolio → Valuation → Investment breakdown (and in the NAV History detail view).

Add account
Click any row below to rename it or edit its description. Add custom accounts for anything specific to your fund — e.g. a separate custody fee expense, a receivable, or an additional income category — and optionally nest one under an existing account (e.g. "Bank — GTBank" under Cash and Cash Equivalents) to build a sub-account whose balance rolls up into its parent's total. New accounts appear automatically in the Journal, General Ledger, Trial Balance, and Financial Statements.
🔒 This is a built-in account — only its name and description can be changed. Code and type are locked because the fund's automatic postings reference them directly.
